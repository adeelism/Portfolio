03 How I work

Spec-driven

Requirements become versioned specs — user stories, acceptance criteria, business rules, an error catalogue, and an API contract — before any code.

Test-first

Every acceptance criterion and catalogued error maps to a test. Coverage is a floor, not a goal; CI gates lint, types, and tests.

AI-assisted

Plans are produced and reviewed against the spec before execution — AI-assisted with Claude Code, with judgement kept at the spec and review gates.
